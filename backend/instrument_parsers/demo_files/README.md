# Demo instrument files

Made-up values for a glycobiology lab demo (sialyltransferase MBP-ST6GAL1, SHuffle E. coli). No real
people or measurements. They are written in each vendor's real export layout so the parsers read
them like the real thing.

| File | What it is |
|---|---|
| gen5_sialyltransferase_phosphate_assay.txt | Gen5 plate export, malachite-green phosphate release (A620), standards in columns 1-2 |
| nanodrop_purified_MBP_ST6GAL1.txt | NanoDrop 8000 export, protein A280 of purification fractions |
| cfx_ST6GAL1_knockdown_cq.csv | CFX Maestro Cq export, ST6GAL1 vs GAPDH after siRNA knockdown |
| unicorn_MBP_ST6GAL1_NiNTA_run.zip | UNICORN result (AKTA pure), Ni-NTA run with imidazole elution. Built on the zip structure from allotropy's test data (MIT) with new curves |
| gel_SDS_PAGE_MBP_ST6GAL1_16bit.tif | 16-bit grey TIFF of a stain-free SDS-PAGE gel (synthetic bands) |
| sanger_ST6GAL1_insert_T7.ab1 | ABI sequencing trace (invented sequence, four channels) |
